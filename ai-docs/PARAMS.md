# 能力与行为参数

> 本文件由 `python tools/params_doc.py` 从代码生成，请勿手改。
> 角色怎么写见 [CHARACTERS.md](CHARACTERS.md)，整体结构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

角色定义（`slugcatpet/resources/characters/<key>.json`）里这样覆盖参数：

```json
"abilities": {"tongue": {"ceiling_drop": false}, "ascension": {}},
"behaviors": {"cursor_lick": {"dwell_ticks": 120}, "dodge_kill": false}
```

- `abilities`：这只猫有哪些能力（键）以及参数覆盖（值，`{}` = 全用默认）。
- `behaviors`：行为按能力自动挂载，这里只写例外：`false` 关掉，对象 = 覆盖参数。
- 带心情候选的行为，权重还会乘以性格权重（好动度 × `toy_pref[心情名]`）。

## 性格

角色 JSON 的 `personality` 各轴作用如下，换算都在 `characters/personality.py` 的 `Traits` 里。

| 轴 | 作用 |
|---|---|
| `activity` | 心情候选权重、玩耍体力门、东张西望和踱步频率 |
| `toy_pref` | 按心情名单独调权重 |
| `stamina` | 体力消耗 |
| `cold_gain_fac` | 暴风雪里变冷的速度 |
| `sociability` | 发呆走位：靠近或远离其他猫 |
| `swim_zeal` | 漂游最大深度、潜泳冲刺距离 |
| `diet` | 哪些可食物会去吃、肉的优先度 |

## 能力

### 舌头 `tongue`

射舌粘物收绳；规划器多出舌够 / 舌爬 / 竖杆舌钩 / 舌吊驻留 / 吊顶落体，取果可空中抢射补救。

- 内置角色：`saint`
- 随之挂载的行为：`seek_hpole`、`wall_climb`、`cursor_lick`、`dodge_kill`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `ceiling_drop` | true |  | 规划器可用「爬上天花板横移再松舌落下」（最贵的兜底够取方式） |

### 超度 `ascension`

业力满时可超度：悬浮升空 + 全屏幽灵触手特效（何时触发见行为 ascend）。

- 内置角色：`saint`
- 随之挂载的行为：`ascend`

无可调参数。

### 爆破 `pyro`

空中爆跳（手动控制可招架）；每跳燃料 +1、随时间回落，过热眩晕、满了自爆；水下憋气降到 drown_burst_air 即溺爆。AI 只在燃料 ≤ heat_cap 时爆跳，永不自爆。

- 内置角色：`artificer`
- 随之挂载的行为：`pyro_romp`、`pyro_maul`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `heat_cap` | 5 | 0 ~ 9 | AI 自主爆跳的燃料上限（默认 = 过热警告线，AI 永不至眩晕 / 自爆） |
| `drown_burst_air` | 0.65 | 0 ~ 0.95 | 水下憋气剩余降到此值即溺爆（也是气量条的死亡下界） |

### 高后空翻 `acrobat`

规划器可用加强后空翻够取高处目标；行为后空翻上横杆 / 后空翻劫持光标随之挂载。

- 内置角色：`rivulet`
- 随之挂载的行为：`riv_flip`、`riv_snatch`

无可调参数。

### 水生 `aquatic`

水生体质（潜泳冲刺 / 低水阻 / 浮泳拖臀）。耗气倍率另见数值 lungs_fac。

- 内置角色：`rivulet`

无可调参数。

## 行为

### 取果 `fetch`

饿了去拿能吃的东西（果子、黏菌、蝙蝠），叼回来吃。

- 需要能力：无（所有猫）
- 用到的物品：`edible`

无可调参数。

### 生气扔石头 `anger`

被砸晕或惹急后生气：捡起能扔的东西瞄准光标扔，消气前一直盯着。

- 需要能力：无（所有猫）
- 用到的物品：`throwable`

无可调参数。

### 爬杆 `poles`

无聊时去爬竖杆、站杆顶；横杆上吊挂和行走的状态也在这里。

- 需要能力：无（所有猫）
- 用到的物品：`climbable`

无可调参数。

### 发呆 `idle`

默认状态：站着发呆、东张西望、踱步、对视；无重力时漂浮。心情抽签也在这里发起。

- 需要能力：无（所有猫）

无可调参数。

### 取暖 `warmth`

冷了去暖源旁边取暖，冷度越高越想去；冷到阈值就强制去。

- 需要能力：无（所有猫）
- 用到的物品：`warm`

无可调参数。

### 休息 `rest`

体力告急强制趴下；困了睡觉、被叫醒；饱食满了冬眠。

- 需要能力：无（所有猫）

无可调参数。

### 游泳 `swim`

落水后的游泳状态：漂游、潜泳取食、在水面休息。喜不喜欢水看性格 swim_zeal。

- 需要能力：无（所有猫）

无可调参数。

### 让路 `makeway`

挡了别的猫的路时让开（跳开或趴下让对方跳过）；自己被挡太久就跳过去。

- 需要能力：无（所有猫）

无可调参数。

### 找横杆 `seek_hpole`

场上有横杆时，想玩就用舌头钩上去（高杆先爬墙再钩），之后横杆玩耍。

- 需要能力：`tongue`
- 心情名（toy_pref 键）：`hpole`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.72 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.3 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.0035 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.0006 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |
| `energy_fac_fresh` | 1.3 | 0 ~ 10 | 体力满时的权重系数 |
| `energy_fac_tired` | 0.1 | 0 ~ 10 | 体力空时的权重系数 |

### 爬墙 / 天花板玩耍 `wall_climb`

走到墙脚用舌头爬上天花板吊着晃，玩腻了松手落下。

- 需要能力：`tongue`
- 心情名（toy_pref 键）：`ceiling_play`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.75 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.1 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.0018 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.00038 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |
| `energy_fac_fresh` | 1.3 | 0 ~ 10 | 体力满时的权重系数 |
| `energy_fac_tired` | 0.15 | 0 ~ 10 | 体力空时的权重系数 |

### 舔光标 `cursor_lick`

光标停在屏幕中下部、离猫够近够久：伸舌去舔（好感越高等得越短），舔到加好感。

- 需要能力：`tongue`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `dwell_ticks` | 200 | 1 ~ 4000 | 光标驻留基准 tick（好感 -1 时 ×1.5，+1 时 ×0.5） |
| `gate_frac` | 0.333333 | 0 ~ 1 | 光标与猫水平距离 < 屏宽 × 此值才会舔 |
| `relick_cooldown` | 60 | 0 ~ 100000 | 舔完后的冷却 tick |
| `temper_gain` | 0.1 | -1 ~ 1 | 成功舔到一次的好感变化 |

### 超度 `ascend`

业力满且好感 ≤ temper_gate 时：杀死弹窗出现、被拎住 grab_ticks、被砸晕醒来，都会超度（比躲杀优先）。

- 需要能力：`ascension`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `temper_gate` | -0.2 | -1 ~ 1 | 好感 ≤ 此值（且业力满）才会超度 |
| `grab_ticks` | 200 | 1 ~ 100000 | 被光标拎住这么久（tick）且满足条件 → 超度 |

### 舌头躲杀 `dodge_kill`

杀死弹窗出现时用舌头点「取消」（够不到就先爬墙）；游泳中不躲。被这样取消会扣好感。

- 需要能力：`tongue`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `cancel_temper` | -0.2 | -1 ~ 1 | 自己用舌头取消杀死弹窗时的好感变化 |

### 后空翻上横杆 `riv_flip`

无聊时找一根够得着的横杆，走到杆下后空翻上去，抓住就转横杆玩耍，抓不上落地收工。

- 需要能力：`acrobat`
- 心情名（toy_pref 键）：`riv_flip`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.72 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.3 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.004 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.00055 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |

### 后空翻劫持光标 `riv_snatch`

光标停在离地不高处够久：跑位、后空翻掠过时叼走光标，落地后贴身带着它走一会再放开。

- 需要能力：`acrobat`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `dwell_ticks` | 200 | 1 ~ 4000 | 光标在高度带内停留多少 tick 才触发 |
| `carry_min` | 200 | 1 ~ 4000 | 叼住后最短带多久（tick） |
| `carry_max` | 400 | 1 ~ 4000 | 叼住后最长带多久（tick） |
| `cooldown` | 1200 | 0 ~ 100000 | 成功劫持后的冷却（tick） |
| `cooldown_abort` | 300 | 0 ~ 100000 | 放弃 / 扑空后的冷却（tick） |

### 爆跳撒欢 `pyro_romp`

无聊时找块空地连续爆跳几下；燃料不够一整轮就不玩。

- 需要能力：`pyro`
- 心情名（toy_pref 键）：`pyro_romp`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.72 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.3 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.004 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.00055 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |
| `jumps` | 2 | 1 ~ 5 | 一轮连跳次数 |

### 爆跳扑咬 `pyro_maul`

好感低时，光标从身边经过后移远：概率爆跳扑上去叼住；光标贴身停留：走过去叼住。叼住啃几口后松开。

- 需要能力：`pyro`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `temper_gate` | -0.5 | -1 ~ 1 | 好感 ≤ 此值才会扑咬 |
| `pounce_prob` | 0.3 | 0 ~ 1 | 光标经过后移远时爆跳扑抓的概率 |
| `near_ticks` | 120 | 1 ~ 4000 | 光标贴身停留多少 tick 后走过去叼 |
| `cooldown` | 1200 | 0 ~ 100000 | 扑咬后冷却 tick（两种模式共用） |
